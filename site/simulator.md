# Browser simulator

Read complete worked requests and results below, or enable JavaScript for optional local counting. Each election domain has its own ballot contract, tie policies, and method families; a shared method name does not imply the same rule.

The interactive editor loads the same canonical examples used by the documentation. Changing domain or method replaces the edited request. Reset restores the selected example. Run produces a structured JSON result including the engine's trace. Browser safety limits are intentionally smaller than the API's limits, especially for exhaustive searches; this is a teaching tool, not election administration software.
